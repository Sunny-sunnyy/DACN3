# UI/UX Research Notes

## Current Decision

MVP frontend is chat-first with product result cards.

## What Is Fixed

- User writes Vietnamese.
- Assistant answer is Vietnamese.
- Product names and source data can remain English.
- Prices are USD.
- Result cards show source, sale price, estimated value, discount, and URL.

## What Is Not Fixed

The exact UI visual style is not fixed yet.

Research later:

- chat layout.
- card layout.
- mobile behavior.
- debug panel placement.
- typography.
- color system.
- loading states.

## MVP UX Requirements

- User understands job is running.
- User can see which source each product came from.
- User can click product URL.
- User can see if result is partial or source failed.
- Debug `job_id` is accessible for troubleshooting.

## Brainstorming And Research Gate

Before implementation, coding agents must run a focused brainstorming/research pass to validate assumptions, simplify scope, and update this document if a better approach is found.
