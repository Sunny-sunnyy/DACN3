```text
required command starts

required external service connection works hoặc được mock/skip có lý do
app/service starts
smoke test works
no immediate fatal path/runtime error
```

Nếu project có test suite:

```text
tests should run
```

Nếu có frontend:

```text
install/build/dev-start should be verified
```

Nếu có Docker Compose:

```text
compose config/up should be verified where required
```

Nếu có Qdrant/vector store:

```text
storage compatibility must be checked
```
